# Prospects

Meeting logs, outreach logs, deal risks and per-account collateral. One folder per
account, meeting files named `YYYY-MM-DD-<what-it-was>.md`.

Notes are written from debriefs, not transcripts — anything not directly confirmed by
the prospect is marked _(unverified)_.

Read `../gtm/` before acting on any of this: the sales playbook, the legal/pricing
constraints and the Korean scripts govern how these accounts get worked.
